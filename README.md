# GARSEF 2026-2027 club course updates

A read-only website that mirrors announcements, modules, assignments, and meeting dates for the GARSEF 2026-2027 club course.

Live site: https://vitteshtaneja.github.io/garsef-course-updates/

This page is public and view-only. It does not provide login or editing access to the course itself.

## Updating content

Edit `data.js` only. That file defines a single `window.COURSE` object with the course name, last-updated time, announcements, modules, assignments, and meetings. Commit the change on `main` and the site will pick it up after GitHub Pages rebuilds.

Course file links require an Eanes ISD login. Google, YouTube, and fair website links are public.

## Local preview

Open `index.html` in a browser, or serve this folder with any static file server.
